# ledgerinnovation.com

Company website of Ledger Innovation MB. A single static page, no build step.

- `index.html`, `style.css` - the page
- `assets/` - product icons, Open Graph image, touch icon
- `ledger-innovation-mark.svg` - logo mark, also the favicon

Published with GitHub Pages from the `master` branch (`CNAME` sets the domain).
To preview locally, open `index.html` in a browser or run `python3 -m http.server` in this folder.
